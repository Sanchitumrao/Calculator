# 🚀 Features
**➕ Simple Calculator:**
Supports addition, subtraction, multiplication, division and square .
Clean and minimal interface for quick calculations.

**🔄 Currency Converter:**
Converts between multiple currencies.
Uses up-to-date exchange rates (connected to an API).

**⚖ BMI Calculator:**
Input height and weight to calculate BMI.
Provides category results (Underweight, Normal, Overweight, Obese).

**🔢 3 in 1 calculator:**
That combines three useful tools into one

🔹Clean and responsive design. 

🔹Both desktop and mobile friendly.
